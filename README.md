# FullDomain Theory Learning Material

Welcome to the **eyeBRO — The Ultimate JavaScript, Node.js, & MongoDB Master Cheatsheet**.

This repository contains a highly interactive, 3D animated, and multi-sensory educational web experience designed to make learning web development fun and engaging.

## 🛠️ Features
- **3D Vault Door Entrance**: An immersive animated entry screen.
- **Dynamic Theming**: Color palettes automatically shift as you scroll between JavaScript, Node.js, and MongoDB sections.
- **Ambient Multi-Sensory Audio**: Custom Web Audio API synthesized sound effects.
- **Responsive Layout**: Works flawlessly on desktop and mobile.
